# Персонализированный тренажёр для начальной школы

## Назначение программы

Программа реализует консольный тренажёр для закрепления знаний по темам начальной школы. Вопросы загружаются из текстового файла `questions.txt`. После прохождения сессии программа сохраняет результаты в файл `user_answers.txt`. При следующем запуске часть вопросов выбирается с учётом ошибок прошлой сессии.

Решение соответствует уровню **«хорошо»**: программа учитывает факт предыдущего запуска, сохраняет результаты и повторно предлагает вопросы, на которые пользователь ранее ответил неверно. Категория вопроса хранится в файлах, но не используется для подбора вопросов. Полный подбор по категориям относится к уровню «отлично».

## Состав проекта

```text
personalized_trainer_good/
├── trainer.py          # основной файл программы
├── questions.txt       # база вопросов, 50 строк
├── user_answers.txt    # файл результатов, создаётся/обновляется программой
└── README.md           # документация
```

## Требования

Для запуска нужен Python 3.10 или новее. Дополнительные библиотеки не требуются.

## Запуск

Откройте папку проекта в терминале и выполните команду:

```bash
python trainer.py
```

Если используется Linux или macOS, команда может выглядеть так:

```bash
python3 trainer.py
```

## Формат базы вопросов

Файл `questions.txt` хранит вопросы построчно. Разделитель полей — точка с запятой.

```text
id;category;subject;question;answer
```

Назначение полей:

1. `id` — уникальный номер вопроса;
2. `category` — номер категории;
3. `subject` — название предмета;
4. `question` — текст вопроса;
5. `answer` — правильный ответ.

Пример строки:

```text
1;1;Математика;Сколько будет 7 + 5?;12
```

Если допустимо несколько вариантов ответа, они записываются через вертикальную черту:

```text
43;3;Окружающий мир;Какой орган помогает человеку дышать?;легкие|лёгкие
```

## Формат файла результатов

Файл `user_answers.txt` создаётся программой автоматически. После каждой сессии старое содержимое очищается, затем записываются новые результаты.

Формат строки:

```text
question_id;category;error_status
```

Где:

- `question_id` — номер вопроса;
- `category` — категория вопроса;
- `error_status` — статус ошибки: `0` означает правильный ответ, `1` означает ошибку.

Пример:

```text
12;1;0
27;2;1
43;3;1
```

## Алгоритм работы

1. Программа проверяет наличие непустого файла `user_answers.txt`.
2. Если файл отсутствует или пустой, выбираются 10 случайных вопросов из базы.
3. Если файл уже есть, программа читает номера вопросов с ошибками.
4. В новую сессию добавляется до 5 вопросов, на которые раньше был дан неправильный ответ.
5. Остальные вопросы добираются случайным образом из базы.
6. Пользователь отвечает на 10 вопросов.
7. Программа выводит отчёт: количество правильных ответов, количество ошибок и процент выполнения.
8. Файл `user_answers.txt` очищается и заполняется результатами новой сессии.

## Пример контрольного запуска

Первый запуск:

```text
Предыдущая сессия не найдена. Будет создана случайная сессия.
Вопрос 1 из 10
Предмет: Математика
Задание: Сколько будет 7 + 5?
Ваш ответ: 12
Верно!
```

Фрагмент отчёта:

```text
Отчёт о прохождении
Всего отвечено: 10
Правильных ответов: 8
Ошибок: 2
Результат: 80.0%
```

Следующий запуск:

```text
Найден файл результатов предыдущей сессии.
```

В новую сессию будут включены вопросы, на которые в прошлый раз были даны ошибочные ответы.

## Как загрузить в репозиторий

1. Создайте репозиторий на `git.uspu.ru`.
2. Добавьте в репозиторий файлы `trainer.py`, `questions.txt`, `README.md`.
3. Файл `user_answers.txt` можно добавить пустым или не добавлять, так как программа создаёт его сама.
4. Пригласите преподавателя в соавторы через настройки проекта.
5. Отправьте преподавателю ссылку на репозиторий.
